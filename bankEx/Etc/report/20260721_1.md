## 개요

일반대출 상환 시 원금만 차감되던 기존 `repay()` 로직을 개선해, 상환 방식별(원금균등/만기일시) 이자 계산과 상환 이력 저장 기능을 추가했다. 명세는 `plainText.md` 섹션 3(일반대출 이자 계산 보완)으로 사용자가 사전에 작성해 전달했다.

이번 작업은 **planner → developer → reviewer → tester** 4단계 서브에이전트 파이프라인으로 진행했다. planner가 기존 코드 전체를 분석해 구현 계획을 수립했고, developer가 신규 파일 9개·수정 파일 6개를 구현했다. reviewer가 코드 리뷰에서 HIGH 이슈 4건·MEDIUM 이슈 4건을 발견했고, 즉시 수정 후 tester가 테스트 15건을 작성·실행해 전부 통과시켰다.

### 핵심 계산 로직

```
월 이자율  = 연 이자율(%) / 12 / 100
월 이자    = 잔여 원금 × 월 이자율  (소수점 HALF_UP 반올림, 원 단위)

EQUAL_PRINCIPAL (원금균등):
  - 고정 원금 = 총 대출 원금 / 대출 기간  (HALF_UP 반올림)
  - 실제 원금 = min(고정 원금, 잔여 원금)  (마지막 회차 및 중도 잔액 보호)
  - 마지막 회차 = 잔여 원금 전액

BULLET (만기일시):
  - 중간 회차 = 원금 0, 이자만 납부
  - 마지막 회차 = 잔여 원금 전액 + 이자

총 납부액 = 원금 + 이자
```

### 신규 API

| 메서드 | 경로 | 설명 |
|---|---|---|
| POST | `/api/bank/user/loans/{loanId}/repay` | 이자 포함 상환 실행. 계좌 출금 → 잔여 원금 차감 → 이력 저장 → 잔여 0이면 상환완료 처리 |
| GET | `/api/bank/user/loans/{loanId}/repayment-preview` | 이번 회차 예상 납부액 조회 (DB 변경 없음) |
| GET | `/api/bank/user/loans/{loanId}/repayment-history` | 상환 이력 전체 조회 |

기존 `POST /api/bank/user/loan/repayment` (원금만 차감)는 하위 호환을 위해 그대로 유지.

### DB 변경사항

```sql
-- LOAN_APPLICATION 기존 테이블에 컬럼 추가
ALTER TABLE LOAN_APPLICATION ADD REPAYMENT_TYPE VARCHAR2(30);

-- 신규 테이블
CREATE TABLE LOAN_REPAYMENT_HISTORY (
    HISTORY_ID          NUMBER(19) GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    APPLICATION_ID      NUMBER(19) NOT NULL,
    PAYMENT_SEQ         NUMBER(5) NOT NULL,
    REPAYMENT_TYPE      VARCHAR2(30) NOT NULL,
    TOTAL_PAYMENT       NUMBER(15) NOT NULL,
    PRINCIPAL_AMOUNT    NUMBER(15) NOT NULL,
    INTEREST_AMOUNT     NUMBER(15) NOT NULL,
    REMAINING_BALANCE   NUMBER(15) NOT NULL,
    PAID_AT             TIMESTAMP NOT NULL,
    CONSTRAINT UK_LOAN_REPAYMENT_SEQ UNIQUE (APPLICATION_ID, PAYMENT_SEQ),
    CONSTRAINT FK_LOAN_REPAYMENT_APP FOREIGN KEY (APPLICATION_ID)
        REFERENCES LOAN_APPLICATION(APPLICATION_ID)
);
```

> Oracle 운영 DB는 schema.sql 자동 실행 대상이 아니므로 위 DDL을 수동 반영해야 한다.

## reviewer 지적 사항 및 수정 내역

| 심각도 | 파일 | 문제 | 수정 방법 |
|---|---|---|---|

### 커버된 케이스

**LoanInterestCalculatorTest**
- 연 4.8% / 원금 10,000,000 → 월 이자 40,000원
- 연 3.6% / 원금 5,000,000 → 월 이자 15,000원
- EQUAL_PRINCIPAL 10,000,000 / 12개월 → 833,333원 (HALF_UP)
- EQUAL_PRINCIPAL 10,000,000 / 3개월 → 3,333,333원

**LoanRepaymentServiceTest**
- EQUAL_PRINCIPAL 1회차: 원금 833,333 + 이자 40,000 = 총 873,333 / 잔여 9,166,667
- EQUAL_PRINCIPAL 마지막 회차: status "상환완료" 전환
- BULLET 중간 회차: 원금 0, 이자만 납부
- BULLET 마지막 회차: 원금 전액 + 이자
- 존재하지 않는 loanId → LOAN_APPLICATION_NOT_FOUND
- 잔여 원금 0 → LOAN_ALREADY_COMPLETED
- 실행완료 외 상태 → LOAN_NOT_APPROVED
- null repaymentType → LOAN_INVALID_REPAYMENT_TYPE
- preview() 호출 시 transService.debit 미호출 확인
- preview() 반환값 정확성 확인
