1. 일반대출 이자 계산 및 상환 스케줄 개발

1.1 개발 목적

현재 일반대출은 상환 시 원금만 차감하고 있어 실제 대출 업무에 필요한 이자 계산이 누락되어 있다.

일반대출 실행 시 대출금액, 금리, 대출기간, 상환방식을 기준으로 월별 원금과 이자를 계산하고, 상환 예정 내역을 관리할 수 있도록 개선한다.

⸻

1.2 지원 상환 방식

최소한 아래 세 가지 방식을 지원한다.

* 원리금균등상환
* 원금균등상환
* 만기일시상환

LoanProduct 또는 대출 신청 데이터에 상환방식을 구분하는 필드를 추가한다.

repaymentType
- EQUAL_PAYMENT: 원리금균등
- EQUAL_PRINCIPAL: 원금균등
- BULLET: 만기일시상환

1.4 이자 계산 기준

기본 이자는 다음 산식으로 계산한다.

월 이자율 = 연 이자율 / 12 / 100
월 이자 = 상환 전 남은 원금 × 월 이자율

일할 계산이 필요한 경우 다음 산식을 사용한다.

이자 = 남은 원금 × 연 이자율 × 사용 일수 / 365

윤년 또는 상품 정책에 따라 365일, 366일 기준은 정책화할 수 있도록 한다.

금액 계산은 double 대신 BigDecimal을 사용한다.

BigDecimal interest =
    remainingPrincipal
        .multiply(annualRate)
        .multiply(BigDecimal.valueOf(days))
        .divide(BigDecimal.valueOf(36500), 2, RoundingMode.HALF_UP);

1.5 상환 처리 로직

기존 repay() 메서드는 단순 원금 차감 방식에서 다음 순서로 변경한다.

1. 상환 대상 회차 조회
2. 납부 예정 이자 계산 또는 스케줄 이자 조회
3. 입금액을 연체이자, 이자, 원금 순서로 충당
4. 남은 원금 차감
5. 상환 스케줄 상태 변경
6. 대출 잔액과 다음 납부일 갱신
7. 거래내역 생성
8. 원금이 0원이면 대출 상태를 COMPLETED로 변경

상환금 충당 순서 예시:

연체이자 → 약정이자 → 원금

2. 입출금통장 예치 이자 개발

2.1 개발 목적

일반 입출금 계좌에도 상품별 기본 이자율을 설정하고, 일정 주기마다 계좌 잔액을 기준으로 예치 이자를 계산하여 지급한다.

⸻

2.2 데이터 구조

이자율은 개별 계좌에 직접 저장하기보다 계좌상품에 설정하는 방식을 권장한다.

AccountProduct 또는 DepositProduct 추가 항목

baseInterestRate       기본 연 이자율
interestCalculationType
interestPaymentCycle
minimumInterestBalance

값 예시:

interestCalculationType
- DAILY_BALANCE: 일별 잔액 기준
- MINIMUM_BALANCE: 기간 중 최저 잔액 기준
- AVERAGE_BALANCE: 평균 잔액 기준
interestPaymentCycle
- MONTHLY
- QUARTERLY
- YEARLY

AccountInfo 추가 항목

lastInterestCalculatedAt
lastInterestPaidAt
accruedInterest

이자 지급 내역 테이블 예시

CREATE TABLE ACCOUNT_INTEREST_HISTORY (
    INTEREST_HISTORY_ID  BIGINT PRIMARY KEY,

    CALCULATION_TO       DATE NOT NULL,
    INTEREST_RATE        DECIMAL(7, 4) NOT NULL,
    BASE_BALANCE         DECIMAL(18, 2) NOT NULL,
    INTEREST_AMOUNT      DECIMAL(18, 2) NOT NULL,
    TAX_AMOUNT           DECIMAL(18, 2) DEFAULT 0,
    PAID_AMOUNT          DECIMAL(18, 2) NOT NULL,
    PAID_AT              TIMESTAMP NOT NULL
);

⸻

2.3 기본 계산 방식

일별 최종 잔액 기준으로 계산한다.

일 이자 = 일 마감 잔액 × 연 이자율 / 365
기간 이자 = 기간 내 일별 이자의 합계

초기 프로토타입에서는 거래 발생 시마다 일별 잔액 테이블을 생성하지 않고, 계좌 거래내역을 기반으로 일 마감 잔액을 계산해도 된다.

추후 대량 계좌 처리를 고려하면 별도의 일별 잔액 테이블을 권장한다.

CREATE TABLE ACCOUNT_DAILY_BALANCE (
    ACCOUNT_ID       BIGINT NOT NULL,
    BALANCE_DATE     DATE NOT NULL,
    CLOSING_BALANCE  DECIMAL(18, 2) NOT NULL,
    PRIMARY KEY (ACCOUNT_ID, BALANCE_DATE)
);

6. 클로드 작업 지시사항

기존 프로젝트의 패키지 구조, 엔티티, API 규칙과 코딩 스타일을 먼저 분석한 뒤 구현한다.

기존 전세대출과 적금의 이자 계산 코드를 복사하여 별도로 구현하지 말고, 공통화할 수 있는 계산 정책과 유틸리티가 있는지 우선 검토한다.

모든 금액과 금리 계산에는 BigDecimal을 사용하며, 상환 및 이체 처리는 반드시 트랜잭션으로 처리한다.

기존 API와의 호환성을 최대한 유지하되, 기존 repay() 응답에는 다음 정보를 추가한다.

  "paymentAmount": 530000,
  "principalAmount": 480000,
  "interestAmount": 50000,
  "remainingPrincipal": 9520000,
  "nextPaymentDate": "2026-08-20"
