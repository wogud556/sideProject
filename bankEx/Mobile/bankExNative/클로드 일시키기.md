너는 Kotlin 기반 Android Native 앱 개발 전문가이자 테스트/리팩토링 담당 에이전트다.

내 목표는 “모바일 웹뷰 형태의 화면을 Android Native 앱 안에 안정적으로 올리는 것”이다.
현재 개발 대상은 Kotlin 기반 Android 앱이며, WebView를 통해 기존 웹 서비스를 모바일 앱처럼 사용할 수 있게 만들고자 한다.

너는 아래 순서로 작업해라.

1. 현재 소스 구조 분석

* Android 프로젝트 구조를 먼저 파악해라.
* MainActivity, WebView 설정, Manifest, Gradle 설정, 네트워크 권한, minSdk/targetSdk를 확인해라.
* WebView가 어디에서 초기화되고 어떤 URL을 로딩하는지 확인해라.

2. 개발 구현

* Kotlin 기반으로 WebView 화면을 안정적으로 구성해라.
* 뒤로가기 처리, 페이지 로딩 상태, 에러 처리, JavaScript 설정, mixed content 정책, SSL/네트워크 오류 처리 기준을 명확히 반영해라.
* 필요 시 WebViewClient, WebChromeClient를 분리해서 관리해라.
* 하드코딩된 URL이나 설정값은 별도 상수/Config로 분리해라.

3. 리팩토링

* Activity에 모든 로직이 몰리지 않도록 구조를 개선해라.
* WebView 설정, 네트워크 상태 체크, 에러 처리, UI 상태 관리를 가능한 한 분리해라.
* 중복 코드 제거, 함수명 개선, 책임 분리를 적용해라.
* 유지보수하기 쉬운 구조로 변경하되, 과도한 아키텍처는 피하고 현재 프로젝트 규모에 맞춰라.

4. 테스트 코드 작성
    다음 테스트를 작성해라.

* WebView 초기 설정 검증 테스트
    * JavaScript 활성화 여부
    * DOM Storage 활성화 여부
    * UserAgent 설정 여부
    * MixedContentMode 설정 여부
* URL 로딩 검증 테스트
    * 앱 실행 시 지정된 URL이 정상적으로 loadUrl 되는지 검증
    * 잘못된 URL 또는 빈 URL이 들어왔을 때 예외/에러 처리가 되는지 검증
* 뒤로가기 동작 테스트
    * WebView가 뒤로 갈 수 있으면 WebView.goBack() 호출
    * 더 이상 뒤로 갈 수 없으면 Activity 종료 또는 기본 back 동작 수행
* 에러 처리 테스트
    * 네트워크 오류 발생 시 에러 화면 또는 재시도 UI가 표시되는지 검증
    * SSL 오류, 페이지 로딩 실패, HTTP 에러에 대한 처리 흐름 검증
* 리팩토링 후 회귀 테스트
    * 기존 기능이 깨지지 않았는지 확인
    * WebView 설정값이 변경 전후 동일하게 유지되는지 확인

5. 테스트 도구 기준

* 가능한 경우 JUnit, Robolectric, MockK를 사용해라.
* Android UI 검증이 필요한 부분은 Espresso 테스트를 고려해라.
* 테스트하기 어려운 WebView 직접 의존 로직은 Wrapper 또는 Helper 클래스로 분리해 테스트 가능하게 만들어라.

6. 검증 방식

* 단순히 코드를 작성하지 말고, 각 테스트가 무엇을 검증하는지 설명해라.
* 테스트 실행 명령어를 제시해라.
* 실패 가능성이 높은 지점을 먼저 지적하고 보완해라.
* 수정 전/후 구조를 비교해서 설명해라.

7. 결과물 형식
    아래 형식으로 답변해라.

* 현재 문제점 요약
* 개선 방향
* 수정/추가할 파일 목록
* 핵심 Kotlin 코드
* 테스트 코드
* 테스트 실행 방법
* 검증 체크리스트
* 추가로 확인해야 할 위험 요소

주의사항: 

* 추측으로 구현하지 말고, 소스 기준으로 판단해라.
* 테스트 불가능한 구조라면 먼저 테스트 가능하도록 리팩토링해라.
* WebView 보안 설정은 반드시 검토해라.
* Android Manifest 권한과 cleartextTraffic 설정 여부도 확인해라.
* 최종적으로 “개발 → 리팩토링 → 테스트 → 검증” 흐름이 명확히 드러나야 한다.

제시한 경로는 현재 너가 있는 위치의 bankExNative 하위 폴더에서 분석 후 개발 진행해주면 돼 위 기준에 따라 먼저 구조를 분석하고 바로 수정하지 말고 작업 계획부터 제시해줘.
